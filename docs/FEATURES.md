# SnapLingo 功能设计文档

## 1. 产品概述

SnapLingo 是一款跨平台的截图、OCR 与翻译工具，提供三大核心功能：
- 截图与编辑
- OCR 文字识别
- 多引擎翻译

## 2. 应用架构

### 2.1 运行模式

- **托盘常驻**：应用在系统托盘常驻，快捷键全局生效
- **主窗口**：Settings Window，包含所有配置和管理功能
- **浮动窗口**：
  - 截图编辑器（全屏覆盖）
  - 贴图窗口（Always on top）
  - Result Window（翻译结果窗口）
  - OCR 结果窗口

### 2.2 托盘菜单

- 截图
  - 普通截图
  - 截图 OCR
  - 截图翻译
- 显示翻译窗口
- 历史记录
- 打开主窗口
- 关于
- 退出

## 3. 截图功能

### 3.1 触发方式

- **普通截图**：`F1`（默认）
- **截屏并自动复制**：`⌘F1`（默认）
- **自定义截屏**：`⇧F1`（默认）

### 3.2 工作流程

1. 按下快捷键，屏幕变暗
2. 出现十字光标选择区域
3. 拖动选择截图范围
4. 进入编辑器模式

**确认选区前的键盘控制**：
- `W` / `A` / `S` / `D`：真实移动鼠标指针 1 像素
- `Tab`：切换检测窗口 / 检测界面元素
- `⌘A`（Windows/Linux 为 `Ctrl+A`）：将截屏区域设为当前屏幕
- `⇧⌘A`（Windows/Linux 为 `Ctrl+Shift+A`）：将截屏区域设为全部屏幕组成的全屏区域
- 以上快捷提示只在选区确认前显示，进入预览/标注后隐藏

### 3.3 截图编辑器（参考 Snipaste）

**工具栏位置**：屏幕顶部中央，半透明黑色背景

**编辑工具**（编辑器内快捷键）：
- 矩形框：工具栏按钮
- 椭圆：`O`
- 箭头：`A`
- 画笔：`P`
- 文字标注：`T`
- 马赛克：`M`
- 撤销/重做：`⌘Z` / `⌘Y`
- 移除所有标注：`⌘⇧Z`
- 显示/隐藏标注工具栏：`Space`
- 工具栏显示时 `Esc` 先隐藏标注工具栏
- 恢复上次成功截图区域：`R`
- 像素级调整选区：按住鼠标左键时使用 `W` / `A` / `S` / `D` 移动、扩大或缩小选区
- 填充/边框切换：`F`（几何图形）
- 完成截图：`Enter` / `⌘C`
- 失去焦点：其他应用窗口被激活时取消当前截图
- 截图记录：只记录复制、保存、快捷保存、贴图这些成功截图动作

**工具属性**：
- 颜色选择
- 粗细/大小调整
- 填充 vs 边框切换（几何图形）

**完成操作**：
- **保存**：保存到配置的默认目录
- **快捷保存**：`⇧` + 保存按钮或 `⌘⇧S`
- **复制**：复制图片到剪贴板，窗口关闭
- **贴图**：图片钉在屏幕上（置顶窗口）
- **取消**：关闭编辑窗口

### 3.4 贴图功能

**触发方式**：
- 截图编辑器完成时选择"贴图"
- 快捷键 `F3`（默认）：将剪贴板内容贴图

**窗口特性**：
- Always on top（始终置顶）
- 可拖动位置
- 方向键逐像素移动
- 可调整大小（拖拽边角或鼠标滚轮）
- 灰度/反色显示：`5` / `6`
- 重置大小/透明度：中键单击
- 缩略图模式：`Shift` + 左键双击
- 左键双击关闭单张贴图

**悬停工具栏**：
- 关闭贴图
- 保存为文件
- 复制到剪贴板
- `Space` 显示/隐藏工具栏，工具栏显示时 `Esc` 先隐藏工具栏

**右键菜单**：
- 调整透明度

**贴图管理快捷键**：
- 隐藏/显示所有贴图：`⇧F3`（默认）
- 切换到另一贴图组：`⌘F3`（默认）
- 打开主窗口/首选项：`⌘⇧P` / `Ctrl+Shift+P`

### 3.5 截图设置

位置：主窗口 → 📸 截图 tab

- 默认保存路径
- 图片格式（PNG/JPG/WebP）
- 图片质量
- 文件命名规则
- 选区边框和自定义遮罩颜色
- 编辑器内调整并记忆标注粗细和字体大小

## 4. OCR 功能

### 4.1 触发方式

- **截图 OCR**：`⇧⌥S`（默认）- 截图 → OCR → 显示结果
- **静默截图 OCR**：默认未设置 - 后台识别，结果到剪贴板
- **访问选图 OCR**：默认未设置 - 文件选择器选择图片
- **显示 OCR 窗口**：默认未设置 - 显示之前的 OCR 结果

### 4.2 工作流程

1. 按下快捷键，选择屏幕区域
2. 自动进行 OCR 识别
3. 弹出 OCR 结果窗口

### 4.3 OCR 结果窗口

**窗口特性**：
- 小窗口（400x300px，可调整）
- 圆角、阴影
- 可拖动

**内容展示**：
- 顶部工具栏：复制、编辑、翻译、关闭
- 中间：识别的文本（可编辑）
- 底部：识别语言、字数统计

**操作**：
- 复制文本
- 编辑文本
- 点击"翻译"按钮 → 跳转到 Result Window

### 4.4 OCR 服务配置

位置：主窗口 → 🔌 服务 tab → [OCR 服务]

**支持的 OCR Provider**：
- Tesseract（内置，本地）
- System OCR（macOS，本地）
- 百度 OCR（需 API Key）

**未来候选 OCR Provider（未实现）**：
- PaddleOCR（插件，本地，中文优化）
- 腾讯云 OCR（需 API Key）
- Google Cloud Vision（需 API Key）
- Azure Computer Vision（需 API Key）

**配置项**：
- 选择激活的 Provider（单选）
- API 配置（如需要）
- 识别语言选择

### 4.5 OCR 设置

位置：主窗口 → 🔍 OCR tab → OCR 设置

- 识别语言优先级
- 结果窗口位置（光标附近/屏幕中央）
- 静默 OCR 将识别文本复制到剪贴板；普通和文件 OCR 只显示结果

## 5. 翻译功能

### 5.1 触发方式

- **划词翻译**：`⌥D`（默认）- 选中文字 → 翻译
- **截图翻译**：`⌥S`（默认）- 截图 → OCR → 翻译
- **显示翻译窗口**：`⌥A`（默认）- 打开翻译窗口，手动输入或查看结果

### 5.2 Result Window（翻译结果窗口，Bob 风格）

**窗口特性**：
- 浮动窗口，圆角阴影
- 默认屏幕中央，可拖动，记住位置
- 单例模式（重复触发时聚焦并更新内容）

**布局结构**：

1. **顶部工具栏**：
   - 固定按钮
   - 收藏按钮
   - 历史按钮
   - 设置按钮
   - 关闭按钮

2. **源文本区域**（灰色背景）：
   - 可编辑文本框（3-5 行）
   - 底部：朗读、复制按钮
   - 源语言标识

3. **语言选择器**：
   - 源语言下拉选择（支持"自动检测"）
   - 双向箭头（交换按钮）
   - 目标语言下拉选择

4. **翻译结果区域**：
   - 多个翻译引擎结果卡片（垂直布局）
   - 每个卡片可折叠/展开
   - 每个卡片有朗读、复制按钮

**Result Window 内快捷键**：
- 关闭窗口：`ESC`
- 复制原文：`⌘C` / `Ctrl+C`
- 复制译文：`⌘⇧C` / `Ctrl+Shift+C`
- 语言交换：`⌘E` / `Ctrl+E`
- 重新翻译：`⌘R` / `Ctrl+R`

**窗口关闭行为**：
- 按 ESC 键关闭
- 点击窗口外关闭（默认）
- 提供"保持打开"开关，勾选后点击窗口外不关闭

### 5.3 翻译服务配置

位置：主窗口 → 🔌 服务 tab → [翻译服务]

**支持的翻译 Provider**：
- Google 翻译（内置，免费）
- DeepL（需 API Key）
- 百度翻译（需 API Key）
- 有道翻译（需 API Key）
- 腾讯翻译君（需 API Key）
- OpenAI（需 API Key，支持 GPT 模型）
- Azure Translator（需 API Key）

**配置项**：
- 启用/禁用服务（多选）
- 服务优先级（拖动排序）
- API 密钥配置
- 支持的语言对

**自定义翻译 Provider**：
兼容以下 API 格式：
- OpenAI 兼容格式
- Claude 兼容格式（Anthropic API）
- Gemini 兼容格式（Google AI Studio）

配置项：
- Provider 名称
- API 格式类型
- API 端点 URL
- API Key
- 模型名称
- 自定义请求头（可选）

### 5.4 翻译设置

位置：主窗口 → 🌐 翻译 tab → 翻译设置

- 源语言默认：自动检测
- 目标语言默认：智能选择（检测到中文→英文，非中文→中文）
- 多服务显示顺序
- 自动复制译文到剪贴板

## 6. 语音合成（TTS）

### 6.1 使用场景

- Result Window 的朗读按钮（原文和译文）
- OCR 结果窗口的朗读按钮

### 6.2 TTS 服务配置

位置：主窗口 → 🔌 服务 tab → [语音合成]

**支持的 TTS Provider**：
- 系统 TTS（内置）
  - macOS: `say` 命令
  - Windows: SAPI
  - Linux: `espeak`
- Azure TTS（需 API Key，支持多语言自然语音）
- OpenAI TTS（需 API Key）

**配置项**：
- 选择激活的 Provider（单选）
- API 配置（如需要）
- 语音选择
- 语速调节

## 7. 历史记录

### 7.1 翻译历史

位置：主窗口 → 🌐 翻译 tab → 历史记录

**记录内容**：
- 时间戳
- 翻译来源（划词/截图/手动）
- 源文本
- 翻译结果（所有激活的 Provider）
- 源语言和目标语言

**功能**：
- 过滤：在统一历史记录中按翻译或 OCR 类型筛选
- 搜索：按源文本或译文搜索
- 删除：单条或批量删除
- 收藏：添加到收藏夹

### 7.2 OCR 历史

位置：主窗口 → 🔍 OCR tab → 历史记录

**记录内容**：
- 时间戳
- 操作类型（截图OCR/静默OCR/访问选图OCR）
- 识别文本
- 原图缩略图（可选）
- 识别语言

**功能**：
- 过滤：全部/截图OCR/访问选图OCR
- 搜索：按识别文本搜索
- 删除：单条或批量删除
- 收藏：添加到收藏夹

### 7.3 自动清理

位置：各功能域的设置中配置

- 启用/禁用自动清理
- 最大保存天数（默认 30 天）
- 最大条目数（默认 1000 条）

**注意**：收藏夹内容不受自动清理影响

## 11. Provider 激活规则

### 11.1 OCR Provider
- **单选**：同一时间只能激活一个
- 用户尝试激活第二个时，系统警告并要求先停用当前激活的

### 11.2 Translation Provider
- **多选**：可以同时激活多个
- 翻译时并发调用所有已激活的
- 结果在 Result Window 中垂直并排显示
- 可拖动卡片调整优先级顺序

### 11.3 TTS Provider
- **单选**：同一时间只能激活一个

## 12. Provider 配置存储

### 12.1 敏感信息
存储在系统级加密存储：
- macOS: Keychain
- Windows: Credential Manager
- Linux: Secret Service

内容：API Key、密钥等

### 12.2 非敏感配置
存储在统一配置文件：`~/.snaplingo/config.json`

内容：
- 语言偏好
- 是否激活
- 超时设置
- 窗口位置和大小

### 12.3 配置持久性
- 配置不随应用卸载删除
- 用户需在"高级 → 数据管理"中主动"清除所有数据"才会删除

## 13. 性能要求

- 截图响应时间：< 100ms
- OCR 识别时间：< 2s（中等长度文本）
- 翻译响应时间：< 3s（多引擎并行）
- 内存占用：< 200MB（后台运行）
- 启动时间：< 1s
