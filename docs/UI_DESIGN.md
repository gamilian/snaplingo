# SnapLingo UI 设计文档

## 1. 设计原则

### 1.1 整体风格
- **现代化简洁风格**：清晰的视觉层级、充足的留白、流畅动画
- **功能优先**：突出核心功能，减少视觉干扰
- **响应式设计**：适配不同窗口尺寸
- **一致性**：统一的颜色、间距、圆角、图标风格

### 1.2 色彩方案
- **主色调**：蓝色（#3B82F6 → #2563EB）
- **辅助色**：
  - 成功：#10B981（绿色）
  - 警告：#F59E0B（橙色）
  - 错误：#EF4444（红色）
- **中性色**：
  - 背景：#F5F5F7（浅灰）
  - 卡片：#FFFFFF（白色）
  - 文字：#1F2937（深灰）
  - 次要文字：#6B7280（中灰）
  - 边框：#E5E7EB（浅灰）

### 1.3 设计参考
- **Anthropic 设计哲学**：技术精确 + 友好亲和
- **图标风格**：2px 描边，圆角端点，简洁几何
- **交互模式**：参考 Bob、Raycast、VSCode 等现代应用

  - 所有：transition-all
  - 变换：transition-transform

### 8.2 hover 效果
- **按钮**：scale-[1.02]
- **卡片**：shadow-lg
- **图标**：scale-110

### 8.3 窗口动画
- **打开**：淡入 + 缩放（从 0.95 到 1）
- **关闭**：淡出 + 缩放（从 1 到 0.95）

### 8.4 折叠动画
- **展开**：max-height 从 0 到 auto，opacity 从 0 到 1
- **折叠**：max-height 从 auto 到 0，opacity 从 1 到 0
- **时长**：200ms
