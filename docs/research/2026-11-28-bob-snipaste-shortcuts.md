# Bob and Snipaste Shortcut Defaults

核查日期：2026-11-28。以下以两款软件官方文档为准，并按 SnapLingo 中可对应的功能整理。macOS 按键符号使用 `⌘` 表示 Command、`⌥` 表示 Option、`⇧` 表示 Shift。

## 官方快捷键

Bob 官方仓库 README 列出：划词翻译 `⌥D`、截图翻译 `⌥S`、输入翻译 `⌥A`、截图 OCR `⇧⌥S`、静默截图 OCR `⌥C`。Bob 的文件选图 OCR 没有默认快捷键。

Snipaste 官方《基础操作》列出：截图 `F1`、贴图 `F3`、隐藏/显示所有贴图 `⇧F3`。官方《内置快捷键》说明 macOS 将 Windows/Linux 的 `Ctrl` 替换为 `Cmd`；《下载》页面将 `Ctrl+F1` 描述为“截图并自动复制”，因此对应 macOS `⌘F1`。

## SnapLingo 默认值

| SnapLingo 功能 | 默认值 | 对照 |
| --- | --- | --- |
| 截图 | `F1` | Snipaste 截图 |
| 截图并自动复制 | `⌘F1` | Snipaste 截图并自动复制 |
| 贴图 | `F3` | Snipaste 贴图 |
| 隐藏/显示所有贴图 | `⇧F3` | Snipaste 隐藏/显示所有贴图 |
| 划词翻译 | `⌥D` | Bob 划词翻译 |
| 截图翻译 | `⌥S` | Bob 截图翻译 |
| 显示翻译窗口 | `⌥A` | Bob 输入翻译 |
| 截图 OCR | `⇧⌥S` | Bob 截图 OCR |
| 静默截图 OCR | `⌥C` | Bob 静默截图 OCR |
| 上传图片 OCR | `⌥O` | SnapLingo 补充；O 对应 OCR。Bob 的文件选图 OCR 未设默认键，Snipaste 无对应功能 |

贴图分组切换 `⌘F3`、贴图边框切换和截图编辑器内单键工具均为 SnapLingo 自有功能，不属于上述软件明确记录的等价动作，因此保留原设置。
