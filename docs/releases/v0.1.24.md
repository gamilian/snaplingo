# SnapLingo v0.1.24

本版将桌面应用迁移至原生 Rust 窗口，并完成跨平台架构和测试体系整理。

## 本版变化

- 桌面运行时从 Tauri / WebView 迁移至原生 Rust：macOS 使用 AppKit，Windows 使用原生窗口和共享 Rust UI。正式安装包不再依赖 WebView2，也不加载 React 前端。
- 设置、翻译结果、截图编辑、贴图与滚动长截图采用共享的界面模型和交互流程，平台宿主负责窗口、输入和系统能力。
- 统一设置中的删除、清空和重置确认，补齐 Windows 单条记录删除确认；关闭窗口、切换页面或重复回调后不会执行过期操作。
- 统一截图保存、OCR、收藏和输出完成流程，保留冻结图像、标注、格式选择与失败后的重试行为。
- 整理桌面入口和独立库的职责，清理旧桥接层、未使用的代码与依赖；原生回归测试直接验证应用库，正式构建不包含测试场景和探针。

## 下载与安装

- macOS 12+：Apple Silicon 下载 `snaplingo-v0.1.24-macos-aarch64.dmg`；Intel 下载 `snaplingo-v0.1.24-macos-x86_64.dmg`。将应用拖入“应用程序”后启动。
- Windows 10 / 11 x64：推荐 `snaplingo-v0.1.24-windows-x86_64-setup.exe`；`snaplingo-v0.1.24-windows-x86_64.msi` 为备选安装器。
- Windows 便携版：下载 `snaplingo-v0.1.24-windows-x86_64-portable.zip`，完整解压后运行 EXE。安装包与便携包均携带本地 OCR 模型和运行依赖，无需 WebView2。
- 更新前退出旧版。正常覆盖安装保留设置、API 配置、数据库和历史记录；便携版请手动解压新版本。

## 签名、权限与已知限制

macOS 使用固定自签名证书，未经 Apple 公证。首次打开如被拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限，选中文本和界面元素检测需要辅助功能权限；从旧 ad-hoc 版本迁移可能需要重新授权。

Windows 安装包未使用公开信任的代码签名，系统可能显示未知发布者或 SmartScreen 提示。请仅从本仓库下载并核对校验值。系统 OCR 需要安装对应语言能力；内置本地 OCR 不依赖系统 OCR 语言包。

本版已完成本机 macOS 原生回归和跨平台编译检查。发布流水线进一步执行 macOS 两种架构与 Windows 的自动化测试、打包及安装启动检查。这些检查不等同于 macOS 各最低兼容版本、Windows 10 / 11 真机、混合 DPI、首次权限授权和真实旧版覆盖升级的完整交互验收；这些场景尚未全部验证。Linux 尚无完整原生桌面宿主，也不提供正式安装包。

## 校验与更新

Release 附带 `SHA256SUMS.txt` 及三个构建目标的来源 JSON，记录版本、源码提交和签名方式。

- macOS：`shasum -a 256 下载的文件.dmg`
- Windows PowerShell：`Get-FileHash .\下载的文件.exe -Algorithm SHA256`

应用的“设置 → 通用 → 关于”可检查更新，并下载、校验和打开对应平台安装包。安装仍由用户确认完成。
