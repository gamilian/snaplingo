SnapLingo v0.1.6 改进了截图编辑中的连续标注体验。

## 主要更新

- 绘制矩形、椭圆、箭头、线条、画笔、高亮、马赛克、橡皮擦或文字后，继续保持当前工具，可以连续创建多个标注。
- 标注完成后不再自动切换到选择状态；手动切换到选择工具后，仍可选中、移动和调整已有标注。
- 修复快速连续标注时被误判为双击复制的问题。
- 改进 macOS 截图窗口在不同 Space 间复用时的窗口状态判断。

## 下载

- macOS 12+ / Apple Silicon：`snaplingo-v0.1.6-macos-aarch64.dmg`
- macOS 12+ / Intel：`snaplingo-v0.1.6-macos-x86_64.dmg`
- Windows x64：优先使用 `snaplingo-v0.1.6-windows-x86_64-setup.exe`；MSI 是备选安装器。

## 校验与已知限制

- 使用 `SHA256SUMS.txt` 校验下载文件。
- macOS 包使用 ad-hoc 签名，未公证；首次启动可能需要在“隐私与安全性”中选择“仍要打开”。
- 免费签名无法保证更换安装包后保留系统授权；需要重新授权时，可在“通用 → 系统权限”处理。
- Windows 包未使用公开信任的代码签名，可能显示 SmartScreen 提示。
