SnapLingo v0.1.12 精简设置页，移除重复的分组标题。

## 本版变化

- 移除通用设置中的重复子标题，以及主题和语音设置里的装饰性标题。
- 保留主题、代理、日志、性能和语音等实际设置项。

## 下载与安装

- macOS 12+ / Apple Silicon：`snaplingo-v0.1.12-macos-aarch64.dmg`
- macOS 12+ / Intel：`snaplingo-v0.1.12-macos-x86_64.dmg`
- Windows x64：优先使用 `snaplingo-v0.1.12-windows-x86_64-setup.exe`；`snaplingo-v0.1.12-windows-x86_64.msi` 为备选安装器。

退出 SnapLingo 后，下载对应平台和架构的安装包并覆盖安装。正常覆盖安装会保留 API 配置和历史记录。

## 签名与权限

macOS 使用固定自签名证书，未经 Apple 公证。首次启动被拦截时，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限；选中文本和界面元素检测需要辅助功能权限。

Windows 当前未使用公开信任的代码签名，可能显示未知发布者或 SmartScreen 提示。仅从本仓库下载并核对校验值。若设备策略阻止运行，请联系设备管理员；不要关闭系统防护。

## 校验

Release 附带 `SHA256SUMS.txt` 和各构建目标的来源 JSON。macOS 可使用 `shasum -a 256 下载的文件.dmg` 校验；Windows PowerShell 可使用 `Get-FileHash .\下载的文件.exe -Algorithm SHA256`。
