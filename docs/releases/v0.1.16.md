# SnapLingo v0.1.16

本版改进了截图选区切换、Windows 截图与快捷键设置，以及原生 OCR 和选中文本翻译的响应稳定性。

## 本版变化

- 截图 WebView 完成事件订阅后才通知原生窗口就绪；截图处理期间保留当前选区画面，减少全屏闪白，并为处理中状态显示轻量进度。
- Windows 截图捕获与 PNG 编码放到后台线程，单屏截图只捕获目标显示器；系统 OCR 也不再阻塞异步运行时。
- Windows 快捷键使用与 macOS 一致的控件布局和图标风格，按键文字显示为 Ctrl、Alt、Shift。
- 修复 Windows 选中文本翻译时快捷键修饰键尚未释放，导致复制内容为空的问题。
- 修复未固定的翻译和 OCR 结果窗口在拖动时因短暂失焦而关闭的问题。

## 下载与安装

- macOS 12+ / Apple Silicon：`snaplingo-v0.1.16-macos-aarch64.dmg`
- macOS 12+ / Intel：`snaplingo-v0.1.16-macos-x86_64.dmg`
- Windows 10 / 11 x64：`snaplingo-v0.1.16-windows-x86_64-setup.exe`；MSI 版本可作为备选。

退出 SnapLingo 后，下载对应平台和架构的安装包并覆盖安装。正常覆盖安装会保留 API 配置和历史记录。

## 签名与权限

macOS 使用固定自签名证书，未经 Apple 公证。首次启动被拦截时，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。从旧 ad-hoc 版本首次迁移可能需要重新授权；截图需要屏幕录制权限，选中文本和界面元素检测需要辅助功能权限。

Windows 安装包未使用公开信任的代码签名，可能显示未知发布者或 SmartScreen 提示。Windows 系统 OCR 需要安装对应语言能力；未安装时请在 Windows 语言设置中补充。

## 校验

Release 附带 `SHA256SUMS.txt` 和构建来源 JSON。macOS 可使用 `shasum -a 256 下载的文件.dmg`；Windows PowerShell 可使用 `Get-FileHash .\下载的文件.exe -Algorithm SHA256` 校验安装包。
