# SnapLingo v0.1.15

本版改进 Windows 系统 OCR 的调用稳定性、截图标注性能，以及 Windows 界面字体和快捷键显示。

## 本版变化

- Windows OCR 复用专用 MTA worker，识别等待设为 30 秒上限；超时会取消本次识别并返回错误，避免无限等待。
- 降低大选区 OCR 的像素缓冲峰值，并在 WinRT 位图创建后立即释放中间缓冲；OCR 输入会缩放到系统支持的尺寸。
- 马赛克绘制只增量处理新笔段，并将采样区域对齐到统一格点，减少拖动延迟并保持像素块连续。
- Windows 界面、选区标注文字和快捷键提示使用 Windows 字体与 `Shift / Alt / Ctrl` 名称。

## 下载与安装

- macOS 12+ / Apple Silicon：`snaplingo-v0.1.15-macos-aarch64.dmg`
- macOS 12+ / Intel：`snaplingo-v0.1.15-macos-x86_64.dmg`
- Windows 10 / 11 x64：`snaplingo-v0.1.15-windows-x86_64-setup.exe`；MSI 版本可作为备选。

退出 SnapLingo 后，下载对应平台和架构的安装包并覆盖安装。正常覆盖安装会保留 API 配置和历史记录。

## 签名与权限

macOS 使用固定自签名证书，未经 Apple 公证。首次启动被拦截时，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。从旧 ad-hoc 版本首次迁移可能需要重新授权；截图需要屏幕录制权限，选中文本和界面元素检测需要辅助功能权限。

Windows 安装包未使用公开信任的代码签名，可能显示未知发布者或 SmartScreen 提示。Windows 系统 OCR 需要安装对应语言能力；未安装时请在 Windows 语言设置中补充。

## 校验

Release 附带 `SHA256SUMS.txt` 和构建来源 JSON。macOS 可使用 `shasum -a 256 下载的文件.dmg`；Windows PowerShell 可使用 `Get-FileHash .\下载的文件.exe -Algorithm SHA256` 校验安装包。
