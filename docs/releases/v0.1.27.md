# SnapLingo v0.1.27

本版改进多窗口设置同步、翻译和 OCR 请求管理，并缩小发布安装包。

## 本版变化

- 缩小应用和安装包：启用发布编译优化、移除符号表，并使用更高压缩率的 macOS DMG。完整保留 PP-OCRv6 small 模型、中文字典、中文字体和许可声明。
- 改进多窗口设置同步：设置按实际修改的字段保存，避免旧窗口的设置快照覆盖其他窗口的新修改。贴图和滚动截图窗口只初始化所需的运行时。
- 改进翻译服务配置：保存服务定义、凭据和排序时统一提交；保存失败时保留原配置。修改服务配置时，已开始的请求继续使用原配置。
- 改进请求取消和退出流程：退出时停止接收新请求、取消运行中的请求，并等待已接收的历史记录写入完成。多服务翻译保留配置顺序，单个服务失败时仍返回其他服务的结果。
- 改进本地 OCR 工作进程管理：取消识别时终止工作进程，识别超过 60 秒时超时退出，并限制同时运行的识别任务，减少重复任务带来的资源占用。

## 下载与安装

- macOS 12+：Apple Silicon 下载 `snaplingo-v0.1.27-macos-aarch64.dmg`；Intel 下载 `snaplingo-v0.1.27-macos-x86_64.dmg`。退出旧版，将应用复制到“应用程序”后启动。
- Windows 10 / 11 x64：推荐 `snaplingo-v0.1.27-windows-x86_64-setup.exe`；`snaplingo-v0.1.27-windows-x86_64.msi` 为备选安装器。
- Windows 便携版：下载 `snaplingo-v0.1.27-windows-x86_64-portable.zip`，完整解压后运行 EXE，保留旁边的 DLL、`ocr` 和 `licenses` 文件夹。
- Windows 需要 Microsoft Edge WebView2 Runtime。普通安装包在缺少运行时时通过联网安装；便携 ZIP 不包含 WebView2，可从 [Microsoft 官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Standalone Installer。
- 正常覆盖安装保留设置、API 配置、数据库和历史记录。便携版请退出旧版后手动解压新版本。

## 签名、权限与验证范围

macOS 使用固定自签名证书，未经 Apple 公证。首次打开如被拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限，选中文本和界面元素检测需要辅助功能权限；从旧 ad-hoc 版本迁移可能需要重新授权。

Windows 安装包未使用公开信任的代码签名，系统可能显示未知发布者或 SmartScreen 提示。请仅从本仓库下载并核对校验值。系统 OCR 需要相应语言能力；PaddleOCR small 不依赖系统 OCR 语言包。

发布流程验证 macOS 两种架构和 Windows 的构建、测试、模型识别及安装启动；Linux 由 CI 验证构建和 OCR 工作进程，目前未提供正式安装包。旧系统、首次授权、多屏混合 DPI 和真实用户环境仍需相应真机验收。

## 校验与更新

Release 附带 `SHA256SUMS.txt` 和各构建目标的来源 JSON，记录版本、源码提交和签名方式。

- macOS：`shasum -a 256 下载的文件.dmg`
- Windows PowerShell：`Get-FileHash .\下载的文件.exe -Algorithm SHA256`

“设置 → 通用 → 关于”可检查更新，下载、校验并打开对应平台安装包。
