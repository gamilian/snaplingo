# SnapLingo v0.1.13

本版修复 Windows 截图在混合 DPI 显示器上的输出尺寸不一致，并改善窄窗口中的标注工具栏布局、划词剪贴板恢复和 OCR 语言提示。

## 本版变化

- 截图预览尺寸提示、标注画布和导出图像使用同一会话像素比例，混合 DPI 下选区预览与保存结果保持一致。
- 标注工具栏按窗口可用宽度定位，窗口较窄时自动换行。
- Windows 划词翻译完成后恢复剪贴板里的常见文本、富文本、图片和文件格式；检测到用户复制了新内容时不会覆盖。
- OCR 结果显示识别引擎实际使用的语言，Windows 系统语言回退也会显示出来。

## 下载与安装

- macOS 12+ / Apple Silicon：`snaplingo-v0.1.13-macos-aarch64.dmg`
- macOS 12+ / Intel：`snaplingo-v0.1.13-macos-x86_64.dmg`
- Windows 10 / 11 x64：`snaplingo-v0.1.13-windows-x86_64-setup.exe`；MSI 版本可作为备选。

退出 SnapLingo 后，下载对应平台和架构的安装包并覆盖安装。正常覆盖安装会保留 API 配置和历史记录。

## 签名与权限

macOS 使用固定自签名证书，未经 Apple 公证。首次启动被拦截时，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。首次从旧 ad-hoc 版本迁移可能需要重新授权；截图需要屏幕录制权限，选中文本和界面元素检测需要辅助功能权限。

Windows 安装包未使用公开信任的代码签名，可能显示未知发布者或 SmartScreen 提示。Windows 截图和剪贴板改动已通过自动化测试；多显示器混合 DPI、真实选区操作和系统 OCR 语言能力仍应在 Windows 10 / 11 桌面环境确认。

## 校验

Release 附带 `SHA256SUMS.txt` 和构建来源 JSON。macOS 可使用 `shasum -a 256 下载的文件.dmg`；Windows PowerShell 可使用 `Get-FileHash .\下载的文件.exe -Algorithm SHA256` 校验安装包。
