# SnapLingo v0.1.0

SnapLingo 首个公开版本，提供截图标注、滚动长截图、OCR、翻译和贴图功能，支持 macOS 与 Windows。

## 功能

- 截图与标注：区域选择、窗口和界面元素检测、放大镜与取色、文字、形状、箭头、马赛克与模糊画笔，支持复制、保存、收藏和贴图。
- 滚动长截图：滚动时持续拼接，往回滚动可收回多截内容，支持撤销和预览。
- OCR：截图、文件图片识别，支持系统 OCR、随包提供的 PaddleOCR small 和可配置的远程服务；结果可复制、朗读和收藏。
- 翻译：划词、截图和文本翻译，多服务结果展示及自定义 LLM 服务配置。
- Windows 划词支持多路径取文：智能／速度模式优先通过 UI Automation 读取选区，空结果、失败或超时后回退模拟复制；质量模式优先复制。直接读取不修改剪贴板，复制路径保留原有剪贴板恢复机制。
- 两端共用设置、截图、翻译和 OCR 窗口布局；统一设置页标题、卡片圆角、留白和快捷键状态，保留系统字体、实际键名及原生窗口差异。
- 提供主题、快捷键、历史记录、收藏、开机启动及应用内更新设置。

## 下载与安装

- macOS 12+：Apple Silicon 下载 `snaplingo-v0.1.0-macos-aarch64.dmg`；Intel 下载 `snaplingo-v0.1.0-macos-x86_64.dmg`。将应用复制到“应用程序”后启动。
- Windows 10 / 11 x64：推荐 `snaplingo-v0.1.0-windows-x86_64-setup.exe`；`snaplingo-v0.1.0-windows-x86_64.msi` 为备选安装器，不必重复安装。
- Windows 便携版：下载 `snaplingo-v0.1.0-windows-x86_64-portable.zip`，完整解压后运行 EXE，保留旁边的 DLL、`ocr` 和 `licenses` 文件夹。
- Windows 需要 Microsoft Edge WebView2 Runtime。普通安装包在缺少运行时时通过联网安装；便携 ZIP 不包含 WebView2，可从 [Microsoft 官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Standalone Installer。

## 旧测试版本迁移

本次将公开版本编号重新从 `0.1.0` 开始。已安装 `0.1.1`–`0.1.33` 测试版本的用户不会收到自动升级提示，请手动下载。Windows 安装器若阻止降级，请退出并卸载旧程序，保留用户数据后安装此版本；不要选择清除应用数据。macOS 退出旧程序后替换“应用程序”中的副本，便携版退出后解压新版本。应用标识和数据目录保持不变。

## 签名、权限与验证范围

macOS 使用固定自签名证书，未经 Apple 公证。首次打开如被拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限，选中文本和界面元素检测按需使用辅助功能权限。

Windows 安装包未使用公开信任的代码签名，系统可能显示未知发布者或 SmartScreen 提示。请仅从本仓库下载并核对校验值。系统 OCR 需要相应语言能力；PaddleOCR small 不依赖系统 OCR 语言包。

发布流程对 macOS 两种架构和 Windows 执行测试、构建、模型识别及安装启动检查。Windows UI Automation 依赖目标应用提供选中文本；不支持时使用复制兜底。低版本系统、多屏混合 DPI、真实应用取文兼容性及两端视觉效果仍需实机验收，编译与自动化测试不代表这些场景已全部验证。

## 校验与更新

Release 附带 `SHA256SUMS.txt` 和各构建目标的来源 JSON，记录版本、源码提交和签名方式。

- macOS：`shasum -a 256 下载的文件.dmg`
- Windows PowerShell：`Get-FileHash .\下载的文件.exe -Algorithm SHA256`

后续公开版本从此基线递增。“设置 → 通用 → 关于”可检查更新，下载、校验并打开对应平台安装包。
