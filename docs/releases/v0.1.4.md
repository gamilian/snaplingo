## 主要更新

- 普通截图默认快捷键调整为 `F1`，菜单提示与“恢复默认值”同步更新。
- 重构截图、OCR／翻译结果与贴图流程，统一多屏坐标换算和会话状态管理。
- 截图工作流统一使用启动时冻结的桌面画面，修复结果取到下层窗口的问题。
- 修复 Windows 多显示器、混合 DPI 与分数缩放下的选区坐标和裁剪。
- 改善截图快捷键、OCR/翻译请求切换与 macOS 系统 OCR 的恢复能力。
- Windows 安装包已构建并完成自动安装验证。

## 下载

- Apple Silicon：`snaplingo-v0.1.4-macos-aarch64.dmg`
- Intel Mac：`snaplingo-v0.1.4-macos-x86_64.dmg`
- Windows x64：优先使用 `snaplingo-v0.1.4-windows-x86_64-setup.exe`；MSI 是备选安装器。

## 校验与已知限制

- 使用 `SHA256SUMS.txt` 校验下载文件。
- macOS 包使用 ad-hoc 签名，未公证；首次启动可能需要在“隐私与安全性”中选择“仍要打开”。
- Windows 包未使用公开信任的代码签名，可能显示 SmartScreen 提示。
