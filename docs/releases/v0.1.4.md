本次为 2026-09-09 更新的 0.1.4 安装包。已安装 0.1.4 的用户请重新下载安装；版本号相同不会显示升级提示，覆盖安装保留原有设置与历史。

## 主要更新

- 简化截图授权弹窗，只保留用途说明、“去授权”和“稍后”；返回系统设置后自动检测，辅助功能按使用需要请求。
- 在“设置 → 通用 → 系统权限”查看授权状态，支持针对 SnapLingo 单项重新授权；仅在 macOS 要求时重启。
- 在“设置 → 通用 → 关于”自动检查最新正式版，按系统和架构下载、校验并打开安装包，无需付费签名服务。
- 修复 macOS 12 多显示器和远程桌面场景下的截图兼容性。
- 普通截图默认快捷键调整为 `F1`，菜单提示与“恢复默认值”同步更新。
- 重构截图、OCR／翻译结果与贴图流程，统一多屏坐标换算和会话状态管理。
- 截图工作流统一使用启动时冻结的桌面画面，修复结果取到下层窗口的问题。
- 修复 Windows 多显示器、混合 DPI 与分数缩放下的选区坐标和裁剪。
- 改善截图快捷键、OCR/翻译请求切换与 macOS 系统 OCR 的恢复能力。
- Windows 安装包已构建并完成自动安装验证。

## 下载

- macOS 12+ / Apple Silicon：`snaplingo-v0.1.4-macos-aarch64.dmg`
- macOS 12+ / Intel：`snaplingo-v0.1.4-macos-x86_64.dmg`
- Windows x64：优先使用 `snaplingo-v0.1.4-windows-x86_64-setup.exe`；MSI 是备选安装器。

## 校验与已知限制

- 使用 `SHA256SUMS.txt` 校验下载文件。
- macOS 包使用 ad-hoc 签名，未公证；首次启动可能需要在“隐私与安全性”中选择“仍要打开”。
- 免费签名无法保证更换安装包后保留系统授权；需要重新授权时，可在“通用 → 系统权限”处理。
- Windows 包未使用公开信任的代码签名，可能显示 SmartScreen 提示。
