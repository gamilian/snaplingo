# SnapLingo v0.1.29

本版加快截图选区显示，改进滚动长截图、多屏弹窗定位，并精简标注工具栏。

## 本版变化

- 更快开始拖框：选区蒙层和窗口位置就绪后即可操作，整屏底图在后台解码。提前完成选区时，预览会在底图就绪后补齐。
- 修复长截图高度不增长：允许滚动前后存在细微像素变化，同时保留重叠区域校验，避免重复或无法判断的画面被错误拼接。
- 精简截图工具栏：主工具栏保持一行，Mosaic 和 Blur 合并为同一入口的两种样式；移除重复的区域高亮入口，保留原有荧光笔。字体、圆角等属性按需展开。
- 修复翻译和 OCR 结果窗的多屏定位：鼠标跟随及居中模式使用原生桌面坐标，在鼠标所在屏幕定位，避免 macOS Retina 和外接屏坐标换算错误。

## 下载与安装

- macOS 12+：Apple Silicon 下载 `snaplingo-v0.1.29-macos-aarch64.dmg`；Intel 下载 `snaplingo-v0.1.29-macos-x86_64.dmg`。退出旧版，将应用复制到“应用程序”后启动。
- Windows 10 / 11 x64：推荐 `snaplingo-v0.1.29-windows-x86_64-setup.exe`；`snaplingo-v0.1.29-windows-x86_64.msi` 为备选安装器。
- Windows 便携版：下载 `snaplingo-v0.1.29-windows-x86_64-portable.zip`，完整解压后运行 EXE，保留旁边的 DLL、`ocr` 和 `licenses` 文件夹。
- Windows 需要 Microsoft Edge WebView2 Runtime。普通安装包在缺少运行时时通过联网安装；便携 ZIP 不包含 WebView2，可从 [Microsoft 官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Standalone Installer。
- 正常覆盖安装保留设置、API 配置、数据库和历史记录。便携版请退出旧版后手动解压新版本。

## 签名、权限与验证范围

macOS 使用固定自签名证书，未经 Apple 公证。首次打开如被拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限，选中文本和界面元素检测需要辅助功能权限；从旧 ad-hoc 版本迁移可能需要重新授权。

Windows 安装包未使用公开信任的代码签名，系统可能显示未知发布者或 SmartScreen 提示。请仅从本仓库下载并核对校验值。系统 OCR 需要相应语言能力；PaddleOCR small 不依赖系统 OCR 语言包。

发布流程验证 macOS 两种架构和 Windows 的构建、测试、模型识别及安装启动；Linux 由 CI 验证构建和 OCR 工作进程，目前未提供正式安装包。旧系统、首次授权、多屏混合 DPI 和真实用户环境仍需相应真机验收。本次选区提速已通过延迟回放和交互回归测试，尚未测量新版在真实快捷键触发下的完整耗时。

## 校验与更新

Release 附带 `SHA256SUMS.txt` 和各构建目标的来源 JSON，记录版本、源码提交和签名方式。

- macOS：`shasum -a 256 下载的文件.dmg`
- Windows PowerShell：`Get-FileHash .\下载的文件.exe -Algorithm SHA256`

“设置 → 通用 → 关于”可检查更新，下载、校验并打开对应平台安装包。
