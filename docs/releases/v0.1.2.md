# SnapLingo v0.1.2

本版完善设置与 Provider 管理，统一界面外观，并修复上传图片 OCR 提前显示旧页面的问题。

## 本版变化

- 设置侧栏调整为「概览与快捷键」「截图」「翻译」「OCR」「服务」「通用设置」「资料库」。翻译和 OCR 各有独立的功能设置，所有翻译、OCR 与语音 Provider 集中在「服务」连续浏览。
- Provider 使用独立卡片，已启用的翻译 Provider 也显示拖动手柄。拖动保留原始卡片尺寸，邻近卡片平滑移动；OCR 排序会持久保存，且不改变当前启用的引擎。
- 新建入口统一为「添加 Provider」，目前支持自定义翻译服务。新建和配置在保留列表的弹窗中完成，支持关闭按钮、点击遮罩和 Esc 退出，高级协议、模型、凭据和策略配置继续可用。
- 界面统一使用 Native 样式，深浅色跟随系统。截图编辑器的填充/描边状态由整个按钮的背景或边框表达，保留自定义标注色板；资料库移除重复标题和数量，保留历史/收藏切换、搜索、过滤和分页。
- 静默截图 OCR 使用与截图 OCR 相同的选区，选区完成后后台识别并直接复制文字，不进入截图编辑器，也不打开 OCR 结果窗口。
- 上传图片 OCR 改用独立系统文件选择器，选图后再显示 OCR 内容。结果窗口在当前内容、尺寸和位置准备好后才显示，过期或重复请求不会重新弹窗。选图期间避免失焦自动关闭和重复打开选择器，取消选图保留原内容。
- 静默截图 OCR 默认快捷键为 `⌥C`，上传图片 OCR 为 `⌥O`；截图 OCR 保持 `⇧⌥S`。默认值用于新配置或恢复默认，升级保留已保存的自定义快捷键。

## 下载与安装

- macOS 12+：Apple Silicon 下载 `snaplingo-v0.1.2-macos-aarch64.dmg`，Intel 下载 `snaplingo-v0.1.2-macos-x86_64.dmg`。退出旧版，将 SnapLingo 拖到“应用程序”覆盖安装。
- Windows 10 / 11 x64：推荐 `snaplingo-v0.1.2-windows-x86_64-setup.exe`，也可选择 MSI 或便携 ZIP。便携版请完整解压并保留附带资源；缺少 WebView2 时需安装该运行时。
- 正常覆盖安装保留设置、服务配置、快捷键、历史和收藏。从历史内部测试版本迁移时，版本编号说明见 v0.1.0 发布记录。

## 签名与验证范围

macOS 复用原有固定自签名证书，未经 Apple 公证。首次打开被拦截时，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限；划词和界面元素检测按需使用辅助功能权限。Windows 安装包未使用公开信任签名。

自动化回归覆盖 Provider 排序及持久化、设置导航、界面外观、静默 OCR 选区交付、结果窗口显示时机、选图取消和防重复选择器。多屏截图、物理快捷键、原生文件选择器的偶现闪屏及跨版本权限保留仍需真实桌面使用验证。

## 校验与更新

Release 附带 `SHA256SUMS.txt` 和各平台构建来源 JSON，记录版本、源码提交和签名方式。macOS 可运行 `shasum -a 256 下载的文件.dmg`；Windows PowerShell 可运行 `Get-FileHash .\下载的文件.exe -Algorithm SHA256`。

已安装公开版的用户可在「通用设置 → 关于」检查更新并下载安装包。
