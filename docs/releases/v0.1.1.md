# SnapLingo v0.1.1

本版更新设置窗口、截图编辑器、桌面贴图及翻译/OCR 浮窗的界面，集中管理快捷键并统一资料库入口，保留现有配置和高级功能。

## 本版变化

- 设置窗口整理为「概览与快捷键」「截图与贴图」「翻译与识别」「引擎与语音」「通用设置」「资料库」六个入口。设置分组直接滚动浏览，移除顶部二级目录。
- 概览展示系统权限、当前 OCR 引擎及已启用翻译引擎。全局快捷键和贴图边框快捷键集中管理，截图编辑器单键改为图标键位卡，支持录制、清除、恢复默认与冲突提示；替换占用键位需明确点击。
- 截图编辑器保留紧凑单行工具栏，将颜色、粗细和填充放入独立快捷属性栏，保留系统调色板及预设色管理。
- 桌面贴图将边框、灰度、反色、缩放、透明度、重置、复制、保存和关闭操作放在图片下方。窗口为停靠栏预留空间，缩放保持图片中心，复制和保存仍使用图片尺寸。
- 翻译结果和服务列表使用随包提供的品牌图标。OCR 浮窗并排展示原图和结果，支持编辑文本、一键翻译和推荐片段复制。
- 资料库统一历史记录和收藏夹入口，保留搜索、过滤、分页及原有记录操作。界面主题、深浅色、高级服务配置、权限修复、容量管理和更新入口继续可用。

## 下载与安装

- macOS 12+：Apple Silicon 使用 `snaplingo-v0.1.1-macos-aarch64.dmg`，Intel 使用 `snaplingo-v0.1.1-macos-x86_64.dmg`。退出旧版后将 SnapLingo 复制到“应用程序”覆盖安装。
- Windows 10 / 11 x64：推荐 `snaplingo-v0.1.1-windows-x86_64-setup.exe`，也可使用 MSI 或便携 ZIP。便携版请完整解压并保留附带资源。
- 正常覆盖安装保留设置、服务配置、历史和收藏。从旧的 `0.1.2`–`0.1.33` 内部测试版本迁移时仍需手动下载，版本编号重置说明见 v0.1.0 发布记录。

## 签名与验证范围

macOS 继续使用原有固定自签名证书，未经 Apple 公证。首次打开若被系统拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限；划词和界面元素检测按需使用辅助功能权限。Windows 安装包未使用公开信任签名。

本版通过前端测试、生产构建和浏览器交互检查。自动化覆盖单页导航、键位冲突、OCR 翻译入口及贴图窗口尺寸计算；实际多屏截图、系统快捷键录制、原生窗口拖动、剪贴板、在线服务及跨版本权限保留仍需桌面实测。

## 校验与更新

Release 附带 `SHA256SUMS.txt` 和构建来源 JSON。macOS 可运行 `shasum -a 256 下载的文件.dmg` 核对校验值。已安装公开版 v0.1.0 的用户可在“通用设置 → 关于”检查更新。
