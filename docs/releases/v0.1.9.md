SnapLingo v0.1.9 新增三套界面主题，修复截图窗口启动卡顿，并让 macOS 发布版使用固定自签名身份。

## 主要更新

- 新增澄明（Native）、夜航（Studio）、松间（Paper）三套界面主题，可在“通用 → 界面主题”中选择。
- 界面主题与浅色、深色、跟随系统的外观模式分别保存，并同步到设置、翻译/OCR、截图和贴图窗口。
- 调整设置导航、服务卡片和历史/收藏布局，精简设置页说明文字。
- 修复 macOS 切换桌面后重建截图窗口时的等待阻塞，避免旧窗口关闭超时造成启动卡顿。
- macOS 两种架构及后续版本复用同一张自签名证书，校验固定证书指纹，避免每次构建改变应用身份。

## 下载与安装

- macOS 12+ / Apple Silicon：`snaplingo-v0.1.9-macos-aarch64.dmg`
- macOS 12+ / Intel：`snaplingo-v0.1.9-macos-x86_64.dmg`
- Windows x64：优先使用 `snaplingo-v0.1.9-windows-x86_64-setup.exe`；`snaplingo-v0.1.9-windows-x86_64.msi` 为备选安装器。

更新前退出 SnapLingo，覆盖安装同一架构版本。正常覆盖安装保留已有设置、API 配置、历史和收藏。

## macOS 权限与签名

本版从 ad-hoc 签名切换到固定自签名证书。**首次升级到本版可能需要重新授予屏幕录制和辅助功能权限一次。**之后的发布版复用同一签名身份，可避免因签名身份变化而失去授权；macOS 仍控制权限是否保留。

如果系统设置显示已允许，但应用仍提示待授权，请在“通用 → 系统权限 → 授权遇到问题？”重新检测；仍不可用时重新授权对应权限，并按 macOS 提示重启应用。

自签名未经过 Apple 公证。首次打开被拦截时，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。用户无需安装根证书。截图需要屏幕录制权限；选中文本与界面元素检测需要辅助功能权限，可以稍后授权，先使用文本翻译和文件 OCR。

## 校验与已知限制

- 使用 `SHA256SUMS.txt` 校验下载文件；每个平台的 `.build.json` 记录源码提交、版本及签名方式。
- Windows 包未使用公开信任的代码签名，可能显示未知发布者或 SmartScreen 提示。
- macOS 与 Windows 默认使用系统 OCR；Windows 需要安装对应的系统 OCR 语言能力。
- 多显示器、全屏桌面和真实跨版本权限延续仍需按实际设备情况验证。
