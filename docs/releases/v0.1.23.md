# SnapLingo v0.1.23

本版补齐截图编辑、滚动长截图、贴图管理和 Windows 便携包，并统一浮窗界面缩放。

## 本版变化

- 增加滚动长截图：支持向上/向下拼接、固定页眉页脚、分段撤销、实时穿透预览和视口边框；可调整高度上限，到达上限自动复制并保存。
- 增强截图标注：支持区域高亮和模糊、聚光灯、圆角、曲线箭头和控制柄，以及系统字体、粗体、斜体、中文输入与文字大小调整。
- 改进编辑操作：滚轮可调悬停标注和模糊强度；支持撤销/重做、标注快捷键录制和“记住上次工具”。
- 完善图片输出：另存为支持 PNG、JPEG 和无损 WebP，按文件后缀选择格式，并记住最近使用的目录和格式；增加 Unix 毫秒命名。
- 扩展贴图管理：可配置边框快捷键、关闭所有贴图、在缩放后复制或保存；支持虚拟桌面居中、缩放时保持中心及透明 PNG。
- 增加单实例启动、关于页第三方许可清单，以及适用于 Windows x64 的便携 ZIP 和校验清单。
- 设置、截图编辑器、长截图控件和光标现在共享界面缩放比例。

## 下载与安装

- macOS 12+：Apple Silicon 下载 `snaplingo-v0.1.23-macos-aarch64.dmg`；Intel 下载 `snaplingo-v0.1.23-macos-x86_64.dmg`。将应用拖入“应用程序”后启动。
- Windows 10 / 11 x64：推荐 `snaplingo-v0.1.23-windows-x86_64-setup.exe`；MSI 可作备选安装器。便携版为 `snaplingo-v0.1.23-windows-x86_64-portable.zip`，解压整个目录后运行 EXE，需要系统已安装 WebView2。在线安装器在需要时下载 WebView2。
- 退出旧版后安装新版本。正常升级会保留本机设置、数据库、API 配置和历史记录。

## 签名与权限

macOS 安装包由固定自签名证书签名，未经 Apple 公证。首次打开如被系统拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。从旧 ad-hoc 版本首次迁移可能需要重新授权。截图需要屏幕录制权限，选中文本和界面元素检测需要辅助功能权限。

Windows 安装包未使用公开信任的代码签名，系统可能显示未知发布者或 SmartScreen 提示。仅从本仓库下载并核对校验值；不要关闭系统防护。

本机 Windows 系统 OCR 需要安装对应的 Windows OCR 语言能力。功能完整性已通过自动化检查；混合 DPI、Windows 原生窗口交互及 Linux X11/Wayland 仍需目标机器验收。

## 校验与更新

Release 附带 `SHA256SUMS.txt` 和各构建目标的来源 JSON。macOS 使用 `shasum -a 256 下载的 DMG`；Windows PowerShell 使用 `Get-FileHash .\下载的文件.zip -Algorithm SHA256`。发行版以各平台构建和安装检查结果为准。
