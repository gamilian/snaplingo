SnapLingo v0.1.10 修复翻译/OCR 窗口拖动时的位置漂移，并恢复服务商列表的拖动排序。

## 主要更新

- 翻译和 OCR 结果窗口在鼠标按下时立即启动原生拖动，避免拖动开始时窗口偏移。
- 服务商排序改为通过专用拖动把手操作，松开后保存新的服务商顺序。

## 下载与安装

- macOS 12+ / Apple Silicon：`snaplingo-v0.1.10-macos-aarch64.dmg`
- macOS 12+ / Intel：`snaplingo-v0.1.10-macos-x86_64.dmg`
- Windows x64：优先使用 `snaplingo-v0.1.10-windows-x86_64-setup.exe`；`snaplingo-v0.1.10-windows-x86_64.msi` 为备选安装器。

更新前退出 SnapLingo，覆盖安装同一架构版本。正常覆盖安装保留已有设置、API 配置、历史和收藏。

## macOS 权限与签名

macOS 使用固定自签名证书，未经 Apple 公证。首次打开被拦截时，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限；选中文本与界面元素检测需要辅助功能权限，可以稍后授权，先使用文本翻译和文件 OCR。

## 校验与已知限制

- 使用 `SHA256SUMS.txt` 校验下载文件；每个平台的 `.build.json` 记录源码提交、版本及签名方式。
- Windows 包未使用公开信任的代码签名，可能显示未知发布者或 SmartScreen 提示。
- macOS 与 Windows 默认使用系统 OCR；Windows 需要安装对应的系统 OCR 语言能力。
