SnapLingo 0.1.5 修复了 macOS 多显示器截图时选区落在错误屏幕的问题。

## 主要更新

- 在 macOS 的 A 屏触发截图快捷键后，冻结底图和选区现在固定显示在 A 屏，不会错误地出现在另一块显示器。
- 修复了“显示器具有单独的空间”开启时，macOS 会把跨屏截图窗口限制到单块屏幕而导致另一块屏幕无法选区的问题。
- 截图会话继续保留完整桌面布局，以保证鼠标坐标、截图输出和已有多屏处理正确。
- 修复 Linux CI 的快捷键显示断言，使其按 Linux 的 Control 键标记验证录制结果。

## 下载

- macOS 12+ / Apple Silicon：`snaplingo-v0.1.5-macos-aarch64.dmg`
- macOS 12+ / Intel：`snaplingo-v0.1.5-macos-x86_64.dmg`
- Windows x64：优先使用 `snaplingo-v0.1.5-windows-x86_64-setup.exe`；MSI 是备选安装器。

## 校验与已知限制

- 使用 `SHA256SUMS.txt` 校验下载文件。
- macOS 包使用 ad-hoc 签名，未公证；首次启动可能需要在“隐私与安全性”中选择“仍要打开”。
- 免费签名无法保证更换安装包后保留系统授权；需要重新授权时，可在“通用 → 系统权限”处理。
- Windows 包未使用公开信任的代码签名，可能显示 SmartScreen 提示。
