# SnapLingo v0.1.33

本版调整截图标注工具，并支持在长截图过程中往回滚动，收回多截的内容。

## 本版变化

- 长截图可以反悔：结果保留起始视口到当前视口的范围，往回滚动时同步缩短长图和预览，继续向外滚动可重新增长；跨过起点后向另一方向扩展。
- 回退后正确导出：撤销记录跟随保留内容更新，连续撤销不会被静止页面立即补回，固定页眉与页脚仍只保留一次。
- 每次新截图选区后默认使用矩形工具；同一次编辑中，切换到马赛克、Blur 等工具后可连续绘制，移除跨截图记忆上次工具的设置。
- Blur 改为圆形画笔：与马赛克一样拖动涂抹，也支持单击点涂。主滑块调整画笔大小，属性面板单独调整模糊强度；预览与导出都沿圆形笔触处理。
- 精简工具栏：移除 Spotlight 按钮，马赛克与 Blur 继续共用入口。

## 下载与安装

- macOS 12+：Apple Silicon 下载 `snaplingo-v0.1.33-macos-aarch64.dmg`；Intel 下载 `snaplingo-v0.1.33-macos-x86_64.dmg`。退出旧版，将应用复制到“应用程序”后启动。
- Windows 10 / 11 x64：推荐 `snaplingo-v0.1.33-windows-x86_64-setup.exe`；`snaplingo-v0.1.33-windows-x86_64.msi` 为备选安装器。
- Windows 便携版：下载 `snaplingo-v0.1.33-windows-x86_64-portable.zip`，完整解压后运行 EXE，保留旁边的 DLL、`ocr` 和 `licenses` 文件夹。
- Windows 需要 Microsoft Edge WebView2 Runtime。普通安装包在缺少运行时时通过联网安装；便携 ZIP 不包含 WebView2，可从 [Microsoft 官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Standalone Installer。
- 正常覆盖安装保留设置、API 配置、数据库和历史记录。便携版请退出旧版后手动解压新版本。

## 签名、权限与验证范围

macOS 使用固定自签名证书，未经 Apple 公证。首次打开如被拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限，选中文本和界面元素检测需要辅助功能权限；从旧 ad-hoc 版本迁移可能需要重新授权。

Windows 安装包未使用公开信任的代码签名，系统可能显示未知发布者或 SmartScreen 提示。请仅从本仓库下载并核对校验值。系统 OCR 需要相应语言能力；PaddleOCR small 不依赖系统 OCR 语言包。

发布流程验证 macOS 两种架构和 Windows 的构建、测试、模型识别及安装启动；Linux 由 CI 验证构建和 OCR 工作进程，目前未提供正式安装包。本轮回归测试覆盖长截图回退、跨起点滚动、固定区域、撤销、预览和导出，以及圆形 Blur 笔触、工具状态和缩放。长截图仍依赖相邻画面的重叠内容，滚动过快或画面无法匹配时会提示放慢滚动。旧系统、首次授权、多屏混合 DPI 和真实用户环境仍需相应真机验收。

## 校验与更新

Release 附带 `SHA256SUMS.txt` 和各构建目标的来源 JSON，记录版本、源码提交和签名方式。

- macOS：`shasum -a 256 下载的文件.dmg`
- Windows PowerShell：`Get-FileHash .\下载的文件.exe -Algorithm SHA256`

“设置 → 通用 → 关于”可检查更新，下载、校验并打开对应平台安装包。
