# SnapLingo v0.1.26

本版统一本地 OCR 为 small / MNN CPU，识别结束后释放模型内存，并恢复 Tauri 桌面实现。

## 本版变化

- macOS、Windows、Linux 的 PaddleOCR 使用相同的 PP-OCRv6 small 检测模型、识别模型和字典，完全离线运行。模型与字典合计约 15.69 MB。
- 每次 OCR 使用独立工作进程，完成后退出，避免模型和推理缓存常驻桌面进程。移除旧的 OCR GPU 开关、ONNX Runtime 和 DirectML 加载路径。
- 截图 OCR 和截图翻译先显示识别中的结果窗口，完成后更新原窗口；关闭窗口、编辑输入或开始新请求后，旧结果不会覆盖新内容。
- 桌面运行时恢复为 Tauri / WebView，沿用截图编辑、贴图、滚动长截图和设置功能。Windows 版本重新需要 WebView2 Runtime。
- 修复固定自签名 macOS 应用加载本地 OCR 时的兼容问题，保留既有签名身份。

本机 Apple M1 Pro / 16 GB 的 small CPU 测试中，小选区中位耗时约 0.18 秒，28 行文档约 1.01–1.04 秒；这些数据包含工作进程启动和模型加载，不包含翻译。完整测量条件和记录见 [OCR 性能报告](https://github.com/gamilian/snaplingo/blob/v0.1.26/docs/research/2026-11-11-small-ocr-benchmark.md)。合成截图测试不代表所有真实输入，也不是准确率验收。

## 下载与安装

- macOS 12+：Apple Silicon 下载 `snaplingo-v0.1.26-macos-aarch64.dmg`；Intel 下载 `snaplingo-v0.1.26-macos-x86_64.dmg`。退出旧版，将应用复制到“应用程序”后启动。
- Windows 10 / 11 x64：推荐 `snaplingo-v0.1.26-windows-x86_64-setup.exe`；`snaplingo-v0.1.26-windows-x86_64.msi` 为备选安装器。
- Windows 便携版：下载 `snaplingo-v0.1.26-windows-x86_64-portable.zip`，完整解压后运行 EXE，保留旁边的 DLL、`ocr` 和 `licenses` 文件夹。
- Windows 需要 Microsoft Edge WebView2 Runtime。普通安装包在缺少运行时时通过联网安装；便携 ZIP 不包含 WebView2，可从 [Microsoft 官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Evergreen Standalone Installer。
- 正常覆盖安装保留设置、API 配置、数据库和历史记录。便携版请退出旧版后手动解压新版本。

## 签名、权限与验证范围

macOS 使用固定自签名证书，未经 Apple 公证。首次打开如被拦截，请在“系统设置 → 隐私与安全性”中选择“仍要打开”。截图需要屏幕录制权限，选中文本和界面元素检测需要辅助功能权限；从旧 ad-hoc 版本迁移可能需要重新授权。

Windows 安装包未使用公开信任的代码签名，系统可能显示未知发布者或 SmartScreen 提示。请仅从本仓库下载并核对校验值。系统 OCR 需要相应语言能力；PaddleOCR small 不依赖系统 OCR 语言包。

发布流程验证 macOS 两种架构和 Windows 的构建、测试、模型识别及安装启动；Linux 由 CI 验证构建和 OCR 工作进程，目前未提供正式安装包。旧系统、首次授权、多屏混合 DPI 和真实用户环境仍需相应真机验收。

## 校验与更新

Release 附带 `SHA256SUMS.txt` 和各构建目标的来源 JSON，记录版本、源码提交和签名方式。

- macOS：`shasum -a 256 下载的文件.dmg`
- Windows PowerShell：`Get-FileHash .\下载的文件.exe -Algorithm SHA256`

“设置 → 通用 → 关于”可检查更新，下载、校验并打开对应平台安装包。
